This repository contains my Day 14 Capstone practical work for the Generative AI for Business course as a BBA Aviation Management student. The capstone focuses on designing, documenting and presenting an end-to-end Generative AI workflow for an aviation-management business problem.

The project follows a structured process: Business Brief → Tool Selection → Prompt Design → Content Generation → Human Review → Source Verification → Final Output. It demonstrates how different AI tools such as ChatGPT, Google Gemini, Canva, Gamma, image-generation tools and document-grounded AI can be selected according to the business task, required output, risk level and verification needs.

The portfolio includes the identification of an aviation-business problem, business brief, workflow mapping, tool-selection matrix and a prompt portfolio containing iterative prompt development and refinement. It also includes workplace-writing and visual outputs, supported by accuracy, tone, compliance and context reviews.

A major focus is responsible AI use. The project includes hallucination and privacy audits, source verification using the Claim → Source → Match → Context → Action routine, and severity × risk assessment for identifying high-risk issues.

The final portfolio contains an 8–12 slide presentation, GitHub documentation, verification evidence, reflection and AI-use disclosure. Overall, this capstone demonstrates how Generative AI can support aviation-management tasks while keeping human judgement, verification, privacy and accountability at the centre of the workflow.
